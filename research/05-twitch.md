# Twitch: API وروابط تنزيل الفيديو

**الخلاصة:** تتيح Twitch تنزيل تسجيلات البث الخاصة بصاحب القناة من واجهة **Video Producer**، لكن وثائق Helix المنشورة تصف `Get Videos` كواجهة بيانات تعريفية، ولا تعرض API لتنزيل ملف VOD كامل أو رابطًا مباشرًا له. توجد واجهة API موثقة لتنزيل **المقاطع القصيرة Clips**، لكنها ليست متاحة لأي شخص لمجرد أن المقطع عام: يلزم اعتماد OAuth بالنطاق المناسب وأن يكون المستخدم محررًا لقناة المذيع. [1] [2] [3]

## تسجيلات البث VOD

عند تفعيل **Store Past Broadcasts** قبل البث، يمكن لصاحب القناة تنزيل تسجيلاته من **Creator Dashboard → Video Producer**: قائمة النقاط بجانب الفيديو ثم **Download**. لا تقدم Twitch خيارًا رسميًا للتنزيل الجماعي عبر Video Producer. [3]

واجهة Helix `GET https://api.twitch.tv/helix/videos` تتيح جلب فيديوهات حسب المعرّف أو القناة أو اللعبة، لكنها ترجع بيانات مثل معرّف الفيديو ورابط صفحة المشاهدة `url` والصورة المصغرة والمدة وعدد المشاهدات، ولا تُظهر رابط تنزيل ملف الفيديو. وتذكر وثائق الفيديوهات أن استخدام API يكون لعرض قائمة الفيديوهات أو حذفها، لا لجلب ملفاتها. لذلك لا يوجد في الوثائق الرسمية المفتوحة هنا API موثق لتنزيل VOD كامل، سواء أكان عامًا أم مملوكًا للمستخدم؛ مسار التنزيل الرسمي الموثق لمالك القناة هو Video Producer. [1]

حفظ VOD يتطلب تفعيل التخزين مسبقًا؛ إذا لم يُحفظ التسجيل أو انتهت مدة الاحتفاظ به، تقول Twitch إنه لا يمكن للدعم استعادته. بحسب صفحة المساعدة، الاحتفاظ هو 7 أيام لمعظم القنوات، و14 يومًا للأفلييت، و60 يومًا للشركاء ومستخدمي Twitch Turbo وPrime. هذا أثر الاشتراك على مدة بقاء التسجيل، وليس خطة مدفوعة للوصول إلى API تنزيل. [3]

## المقاطع Clips: API تنزيل محدودة

توثق Twitch نقطة النهاية `GET https://api.twitch.tv/helix/clips/downloads` لإرجاع رابطَي تنزيل محتملين للمقطع: أفقي `landscape_download_url` وعمودي `portrait_download_url`، وقد يكون أحدهما `null`. هذه روابط مؤقتة، وتحذر الوثائق من توقع صلاحيتها طويلًا. [2]

يتطلب الطلب `broadcaster_id` و`editor_id` ومعرّفًا واحدًا أو أكثر `clip_id`، وبحد أقصى 10 مقاطع في الطلب. يلزم App Access Token أو User Access Token مع أحد النطاقين `editor:manage:clips` أو `channel:manage:clips`. ويجب أن يكون المستخدم محررًا للقناة المحددة؛ تعيد الواجهة 403 إذا لم يكن كذلك. الحد المعلن هو 100 طلب في الدقيقة. النتيجة العملية: هذا مسار لتنزيل مقاطع قناة مخوّل المستخدم بالتحرير فيها، لا رابط تنزيل عام لكل مقطع عام. [2]

كما تسمح واجهة Clips Manager الرسمية بتنزيل النسخ الأفقية أو العمودية من مقاطع قناتك، أو المقاطع التي أنشأتها. وتبين المساعدة أن إعدادات المذيع قد تقيد إنشاء المقاطع أو نشرها مباشرة على خدمات أخرى. [8]

## التضمين ليس تنزيلًا

وثائق Twitch للمطورين تصف تضمين البث وVOD عبر مشغل Twitch داخل `iframe` أو عبر JavaScript Player، وتضمين المقاطع عبر `iframe`. يلزم تحديد `parent` للنطاق الذي يضمّن المشغل، كما أن الحد الأدنى الموثق لحجم مشغل الفيديو 400×300 بكسل. هذه طرق عرض وتشغيل ضمن مشغل Twitch وليست روابط لملف خام. [4]

كذلك فإن `Get Videos` يعيد رابط صفحة Twitch للفيديو، و`Get Clips` يعيد `url` للمقطع و`embed_url` المخصص للتضمين. لا تعني حقول المشاهدة أو التضمين وجود رابط تنزيل. وثائق التضمين الرسمية المفتوحة هنا توثق iframe وJavaScript Player، ولا تعرض oEmbed كطريقة لتنزيل ملف الفيديو؛ أي بيانات تضمين أو oEmbed لا ينبغي التعامل معها على أنها واجهة تنزيل. [1] [4] [5]

## الصلاحيات والحقوق

تستخدم واجهات Twitch رموز OAuth؛ بعض عمليات القراءة تقبل App Access Token، بينما تتطلب العمليات التي تحتاج موافقة صاحب الحساب User Access Token ونطاقات الصلاحيات المناسبة. تنزيل المقاطع يتطلب النطاقات المذكورة أعلاه إلى جانب صفة المحرر للقناة. لا تنص صفحات API المشار إليها على اشتراك مدفوع للوصول إلى هذه الواجهة؛ لكن Twitch Turbo/Prime يرتبطان بمدة الاحتفاظ بــVOD كما سبق، لا بمنح حق تنزيل فيديوهات الآخرين. [2] [7] [3]

شروط Twitch تمنع تنزيل أي جزء من الخدمات أو المواد إلا حيث تسمح Twitch بذلك صراحةً، وتوضح أن إتاحة مشاركة محتوى المستخدمين خارج Twitch تعتمد على تفعيل ميزات المشاركة، مع ترخيص محدود للمشاركة في هذه الحالة. لذا يجب قصر التنزيل وإعادة الاستخدام على المسارات التي تسمح بها Twitch وعلى الحقوق التي يملكها المستخدم أو حصل على إذن بها؛ كون الفيديو عامًا أو قابلًا للتضمين لا يمنح وحده ترخيصًا بتنزيله أو إعادة نشره. [6]

## القرار العملي

- **VOD تملكه:** نزّله من Video Producer بعد تفعيل حفظ البث؛ لا تعتمد على Helix API للحصول على ملف VOD كامل.
- **VOD عام لشخص آخر:** وثائق API الرسمية تعرض بيانات وصفية ومشغلًا، لا API لتنزيل الملف. لا تحاول استنباط روابط وسائط غير موثقة أو تجاوز تسجيل دخول أو قيود وصول.
- **Clip عام:** يمكن قراءة بياناته ورابط تضمينه عبر API، لكن رابط الملف من `Get Clips Download` مشروط بتفويض محرر القناة والنطاقات المحددة.
- **التضمين:** استخدم مشغل Twitch الموثق. التضمين ليس تنزيلًا ولا يساوي حق إعادة الاستخدام.
