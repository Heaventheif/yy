# Vimeo: الوصول الموثق إلى ملفات الفيديو والتنزيل

**النتيجة:** لدى Vimeo واجهة API رسمية تُرجع روابط ملفات فيديو مباشرة، بما فيها روابط تنزيل، لكن ذلك ليس طريقًا عامًا لاستخراج ملف أي فيديو عام. توثيق Vimeo يربط روابط الملفات بتوكن API مصرح له وبميزة `video_files` وبفيديو في حساب عضو مؤهل؛ أما الفيديو العام فيمكن تنزيله من صفحة Vimeo فقط إذا أتاح مالكه التنزيل، ويلزم تسجيل الدخول لتنزيل ملف المصدر. التضمين وoEmbed يعيدان مشغّلًا ومعلوماته، لا ملف الفيديو نفسه. [1] [2] [3] [4]

## API وروابط الملفات

توثيق Vimeo يشرح طلبًا مصادقًا عليه إلى نقطة الفيديو `GET https://api.vimeo.com/videos/{video_id}` لإرجاع حقول روابط الملفات. يشترط دليل روابط الملفات عضوية Vimeo Standard أو أعلى (ويذكر أن خطة Pro القديمة تدعمها)، وتطبيق API، وتوكنًا بنطاقات `public` و`private` و`video_files`. ويصف مرجع المصادقة نطاق `video_files` بأنه يتيح الوصول إلى ملفات الفيديو التابعة لأعضاء لديهم Standard أو أعلى. تُمنح صلاحية الوصول الخاص بتوكن OAuth مرتبط بعضو بعينه؛ لا يكفي توكن public غير المرتبط بحساب للوصول إلى البيانات الخاصة. [1] [2]

توضح صفحة مساعدة Vimeo أيضًا أن حقول `play` و`files` و`download` مختلفة: `play` للبث وروابطه مؤقتة، و`download` روابط تنزيل تنتهي صلاحيتها خلال 24 ساعة، بينما `files` روابط لا تنتهي. قد تكون الروابط تحويلات HTTP 302 إلى CDN، ويجب استعمال رابط التحويل كما أعاده Vimeo؛ الروابط ذات الصلاحية المحدودة تتطلب إعادة طلبها عند انتهاء الصلاحية. هذه آلية رسمية، وليست رابطًا دائمًا مضمونًا للملف الأصلي الخام. [3]

الوثائق تصف رابط API للوصول إلى ملفات الفيديو التابعة لحساب/عضو مصرح، ولا توثق تنزيلًا عامًا غير مصادق عليه لملفات أي فيديو لمجرد أن صفحة الفيديو عامة. كون الفيديو عامًا لا يثبت أن صاحبه سمح بالتنزيل أو أن نطاق `video_files` متاح لمستخدم غير مخول. [1] [2] [4]

## الملف الأصلي مقابل النسخ المحوّلة

يجب التفريق بين نسخة تنزيل من الفيديو وبين ملف الرفع الأصلي. Vimeo يقول إن روابط الملفات تشمل نسخًا متعددة ينشئها من الملف الأصلي وفق مواصفات تقنية مختلفة. أما الاحتفاظ بملف المصدر الأصلي والنسخة الأولية فهو إعداد منفصل يتطلب خطة مدفوعة وتفعيله من إعدادات الحساب، ويبدأ أثره على الرفعات الجديدة؛ لا يستعيد ملفات حُذفت سابقًا. تقول Vimeo إن الملف الأصلي يُحذف افتراضيًا لحسابات Free أو Basic، وكذلك للحساب المدفوع الذي لم يفعّل تخزين المصدر. وقد تُحذف الملفات إذا انتهى الاشتراك أو عُطّل التخزين. [1] [5]

## تنزيل فيديو عام عبر Vimeo

تقول Vimeo إن المشاهد يستطيع تنزيل الفيديو من صفحة الفيديو إذا فعّل المالك خيار التنزيل. لتنزيل ملف مصدر لفيديو عام، يجب تسجيل الدخول إلى حساب Vimeo. لا يدعم مسار الواجهة الرسمي التنزيل الجماعي، كما تنص Vimeo على أن المشاهد لا يستطيع تنزيل الفيديو من المشغّل المضمّن؛ التنزيل المتاح في المشغّل لا يُستنتج من إمكان التضمين. [4] [6]

يمكن لمالك الفيديو ضبط أذونات التنزيل من قسم صلاحيات المشاهد. كما تحذر Vimeo من أن روابط الملفات المباشرة التي ينسخها المالك قد يستطيع أي شخص يملك الرابط استخدامها لتنزيل الفيديو؛ وتقول إن إعدادات الخصوصية والتضمين في Vimeo لا تنطبق على روابط مشغلات الطرف الثالث. لذلك ينبغي التعامل معها كرابط وصول حساس وعدم نشره إلا لمن يحق لهم الملف. [7] [8]

## التضمين وoEmbed ليسا تنزيلًا

توثيق oEmbed يبين أن طلبًا مثل `https://vimeo.com/api/oembed.json?url={video_url}` يعيد بيانات وصفية، وحقل `html` يحتوي عنصر `<iframe>` لتضمين مشغّل Vimeo، إلى جانب العنوان والصورة المصغرة والأبعاد. هذه استجابة تضمين/بيانات وصفية، وليست رابط MP4 أو ملف مصدر قابلًا للتنزيل. وإذا كان الفيديو غير مدرج، يجب إرسال عنوانه كاملًا بما فيه المعرّف الإضافي اللازم. [9]

## الاشتراك والحقوق والقيود

واجهة Vimeo API الأساسية متاحة لمستخدمي وخطط Vimeo دون رسوم بحد ذاتها، لكن بعض الميزات تتطلب خطة مدفوعة؛ وروابط ملفات الفيديو تحديدًا تتطلب Standard أو أعلى وفق دليل المطور الحالي، و`video_files` مقيد بعضوية Standard أو أعلى. تتباين أسماء الخطط الظاهرة في صفحات المساعدة، لذلك ينبغي التحقق من صفحة الخطة الفعلية في الحساب بدل افتراض تطابق أسماء الخطط القديمة. [1] [2] [10]

شروط Vimeo تحفظ لصاحب المحتوى ملكيته الفكرية، وتمنح Vimeo أذونات تشغيل وتضمين وتوزيع عبر API وإتاحة تنزيل، مع النص على تقييد التوزيع وفق إعدادات الخصوصية أو تعطيل التنزيل/التضمين. وفي المقابل، تمنع الشروط الوصول أو التنزيل أو النسخ إلا إذا أذنت به الخدمة صراحة أو أعطى Vimeo إذنًا كتابيًا؛ وتمنع الكشط الآلي خارج API المصرح به، والتحايل على وسائل الأمان أو حدود المعدل أو قيود الوصول. لذا فالتنزيل ينبغي أن يقتصر على محتوى يملكه المستخدم أو لديه تفويض واضح به، وباستخدام API الموثقة أو خيار التنزيل الذي فعّله المالك. [11]

## التوصية العملية

لملفاتك أو الملفات التي فوضك مالكها: استخدم تطبيق API وتوكن OAuth ذي النطاقات المطلوبة لحساب صاحب الملف، وتأكد من استحقاق Standard أو أعلى ومن تفعيل الاحتفاظ بالمصدر مسبقًا إذا كان المطلوب هو ملف الرفع الأصلي تحديدًا. استهلك `download` أو روابط التنزيل الموثقة كما أعادها API، وجدّد الطلب عند انتهاء الصلاحية. للمحتوى العام الذي أذن مالكه بتنزيله، استخدم زر التنزيل في صفحة Vimeo مع تسجيل الدخول عند الحاجة. استخدم oEmbed أو `<iframe>` للمشاهدة المضمّنة فقط، ولا تحاول تجاوز تسجيل الدخول أو CAPTCHA أو الخصوصية أو الأذونات أو حدود API المدفوعة.
