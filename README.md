# نزّل

واجهة عربية لاستخراج روابط الوسائط العامة من منصات مدعومة، مع API مبني على Flask ويعمل على Vercel. يعتمد الاستخراج على `yt-dlp` ومزودات YouTube الخارجية المتاحة في الإعداد الحالي. لا يضمن نجاح كل رابط؛ المحتوى الخاص أو المحمي غير مدعوم.

## التشغيل المحلي

يتطلب Python 3.12 أو أحدث:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

ثم افتح `http://localhost:8000`.

## API

- `GET /api/v1/health` — حالة الخدمة والحدود.
- `GET /api/v1/resolve?url=URL` — استخراج بيانات الوسائط ورابط الخدمة.
- `GET /api/v1/download?url=URL` — تمرير الوسائط مع دعم `Range`.
- `POST /api/v1/batch` — معالجة مجموعة روابط ضمن الحد المضبوط.
- مسارات YouTube مخصصة في `/api/v1/youtube/` تستخدم مزودات خارجية؛ قد تتعطل إذا غيّر المزودون واجهاتهم.

## الإعدادات

| المتغير | الوظيفة |
|---|---|
| `RATE_LIMIT_PER_MIN` | حد طلبات الاستخراج لكل دقيقة لكل نسخة |
| `DL_RATE_LIMIT_PER_MIN` | حد طلبات التنزيل لكل دقيقة لكل نسخة |
| `BATCH_MAX` | أقصى عدد روابط في الطلب الجماعي |
| `EXTRACT_TIMEOUT_SEC` | مهلة الاستخراج؛ الحد الأقصى 10 ثوانٍ |
| `MAX_PENDING_EXTRACTIONS` | أقصى عمليات استخراج متزامنة لكل نسخة |
| `CACHE_TTL_SEC` | مدة الكاش بالثواني |
| `CORS_ORIGIN` | نطاقات CORS المسموح بها |
| `REDIRECT` | تفعيل إعادة التوجيه بدل استجابة JSON عند دعمه |

الكاش ومحدد المعدل في الذاكرة المحلية لكل نسخة، وليسا حدًا عالميًا بين نسخ Vercel. استخدم Vercel Firewall أو خدمة تخزين مشتركة عند الحاجة إلى حماية مركزية.

## النشر

نقطة الدخول هي `app.py`، وملفات الواجهة في `public/`. يعرّف `vercel.json` إعدادات الدالة وسياسة Content Security Policy. اختبر المسارات ومزودي الوسائط بعد النشر؛ قد تتغير سياسات المنصات أو تحجب طلبات الخوادم السحابية.

استخدم الخدمة فقط للمحتوى الذي تملكه أو لديك إذن بتنزيله، مع احترام شروط المنصات وحقوق النشر.
