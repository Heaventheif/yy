# تنزيل — Vercel

شريط تنزيل واحد: الصق الرابط ← يستخرج yt-dlp الملف المباشر ← يبدأ التنزيل.

## النشر
`npm i -g vercel && vercel --prod` (أو استيراد المستودع من GitHub). لا متغيرات مطلوبة.

## الملفات
- `public/index.html` الواجهة (تُخدَّم ثابتة من CDN)
- `app.py` الـ API (`/api/v1/*`) — التوثيق الكامل وطرق الربط في [API.md](API.md)
- `vercel.json` · `requirements.txt` · `.python-version`

## متغيرات اختيارية
| المتغير | الأثر |
|---|---|
| `REDIRECT=1` | تحويل 302 إلى الرابط المباشر بدل تمرير الملف عبر الدالة (يوفّر عرض النطاق، لكن بعض الروابط مقيّدة بـ IP/Referer فتفشل في متصفح المستخدم) |
| `ALLOW_GENERIC=1` | السماح بأي رابط ملف عبر مستخرج generic (يحوّل الخدمة إلى وسيط عام؛ غير موصى به) |
| `PROXY` | بروكسي لطلبات الاستخراج والتنزيل |

## ملاحظات
- يوتيوب محجوب عمدا (الرابط والمستخرجات). لا كوكيز ولا PO Token ولا ffmpeg.
- يُختار ملف واحد جاهز (صوت+فيديو) عبر http(s)؛ بلا دمج ولا HLS.
- أقصى مدة للدالة 300 ثانية؛ المتصفح يستأنف التنزيل الأطول تلقائيا عبر Range.
