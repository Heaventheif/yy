# نزّل (yy)

خدمة ويب وواجهة API لاستخراج معلومات الوسائط وروابطها من روابط عامة على منصات اجتماعية محددة. تعمل الواجهة على Flask، وتستخدم `yt-dlp` لاستخراج الوسائط المدعومة، مع مسار منفصل لصيغ YouTube يعتمد على مزودين خارجيين.

> **مهم:** لا يضمن المشروع نجاح كل رابط. قد تتغير المنصات أو تنتهي صلاحية الروابط المؤقتة أو ترفض الطلبات القادمة من بيئات الاستضافة السحابية. استخدم الخدمة فقط للمحتوى الذي تملكه أو لديك إذن بتنزيله.

## الميزات

- واجهة عربية متجاوبة باتجاه RTL.
- استخراج عنوان الوسائط ونوع الملف ومعلوماته والرابط المباشر عند توفره.
- API لمعالجة رابط واحد أو دفعة روابط، مع خيار بث نتائج الدفعات بصيغة NDJSON.
- تمرير التنزيل عبر الخادم مع دعم `HEAD` و`Range`.
- مسار منفصل لعرض صيغ YouTube وتنزيل الصيغة المختارة، مع رموز تنزيل موقعة قصيرة العمر.
- تحويل محدود لروابط المشاركة والروابط المختصرة، مع التحقق من الوجهات لتقليل مخاطر SSRF.
- كاش قصير، ودمج الطلبات المتطابقة قيد التنفيذ، وحدود محلية للطلبات والتزامن.
- معالجة أخطاء موحدة ومعرّف طلب للمساعدة في التشخيص.

## المنصات

يدعم مسار الاستخراج العام، بحسب ما تسمح به المنصة والرابط، Facebook وInstagram وTikTok وReddit وDailymotion وSoundCloud وFlickr وStreamable.

**YouTube مسار منفصل** ولا يُعالج عبر `/api/v1/resolve`. تستخدم الواجهة مزودين خارجيين للحصول على الصيغ، ثم تمرر الملف عبر نطاق الخدمة. تعتمد هذه الوظيفة على توفر تلك المزودات وسياساتها.

لا تتضمن هذه النسخة تكامل OAuth أو بيانات اعتماد لتنزيل المحتوى المقيّد من Pinterest أو Snapchat أو LinkedIn أو Vimeo أو Twitch؛ لذلك لا تُعد هذه المنصات مدعومة للتنزيل العام هنا. وقد ترفض المنصات المدعومة أيضًا بعض الروابط، أو المحتوى الخاص، أو الروابط المنتهية.

## المتطلبات

- Python 3.12
- الحزم المحددة في `requirements.txt`
- اتصال بالإنترنت للوصول إلى المنصات والمزودات
- FFmpeg متاح عبر `imageio-ffmpeg` أو ضمن بيئة التشغيل، لميزة اقتصاص الصوت

## التشغيل محليًا

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

افتح `http://localhost:8000`.

لتشغيل الاختبارات:

```bash
python -m unittest discover -s tests -v
```

## واجهة API

استبدل `https://YOUR-APP.vercel.app` بعنوان النشر الخاص بك. التفاصيل والأمثلة الكاملة موجودة في [`API.md`](API.md).

| الطريقة | المسار | الوظيفة |
|---|---|---|
| `GET` | `/api/v1/health` | حالة الخدمة والمنصات والحدود الفعلية |
| `GET` | `/api/v1/resolve?url=...` | استخراج معلومات الوسائط والرابط المباشر `direct_url` |
| `POST` | `/api/v1/batch` | معالجة قائمة روابط؛ `?stream=1` لبث NDJSON |
| `GET` / `HEAD` | `/api/v1/download?url=...` | تمرير ملف الوسائط ودعم `Range` |
| `GET` | `/api/v1/youtube/formats?url=...` | الحصول على الصيغ المتاحة لـYouTube |
| `GET` / `HEAD` | `/api/v1/youtube/download?t=...` | تمرير صيغة YouTube باستخدام رمز موقّع |
| `GET` / `HEAD` | `/api/v1/youtube/trim?t=...&start=...&end=...` | اقتصاص مقطع صوتي باستخدام FFmpeg |

مثال لاستخراج رابط:

```bash
curl --get 'https://YOUR-APP.vercel.app/api/v1/resolve' \
  --data-urlencode 'url=https://www.facebook.com/watch/?v=123456789'
```

قد يكون `direct_url` رابط CDN مؤقتًا وقصير العمر. استخدمه فورًا، أو استخدم حقل `download` إذا أردت تمرير الملف عبر الخدمة. لا يعني عمر الكاش أن رابط المصدر سيظل صالحًا طوال تلك المدة.

## الإعدادات

تُضبط الخيارات التالية عبر متغيرات البيئة. القيم الافتراضية موضحة هنا؛ راجع `/api/v1/health` و`API.md` لمعرفة الحدود الفعلية والتفاصيل.

| المتغير | الافتراضي | الغرض |
|---|---:|---|
| `RATE_LIMIT_PER_MIN` | `60` | حد طلبات الاستخراج والدفعات لكل IP في نسخة الخدمة |
| `DL_RATE_LIMIT_PER_MIN` | `20` | حد بدايات التنزيل لكل IP في نسخة الخدمة |
| `BATCH_MAX` | `8` | عدد الروابط الأقصى في الدفعة (حتى 10) |
| `EXTRACT_TIMEOUT_SEC` | `10` | مهلة انتظار نتيجة الاستخراج، بحد أقصى 10 ثوانٍ |
| `MAX_PENDING_EXTRACTIONS` | `4` | عدد عمليات الاستخراج المتزامنة في النسخة، بحد أقصى 8 |
| `CACHE_TTL_SEC` | `75` | مدة الاحتفاظ بنتائج الاستخراج في الكاش المحلي |
| `CORS_ORIGIN` | `*` | قيمة ترويسة CORS؛ يفضّل تحديد أصل الواجهة عند الحاجة |
| `REDIRECT` | `0` | ضبطه على `1` لتفعيل إعادة التوجيه إلى CDN افتراضيًا |
| `SIGNING_SECRET` | — | سر عشوائي طويل لتوقيع روابط تنزيل YouTube؛ اضبطه في الإنتاج |
| `YT_TOKEN_TTL_SEC` | `600` | مدة صلاحية رمز تنزيل YouTube بالثواني |
| `MAX_VIDEO_HEIGHT` | `720` | الحد الأقصى لارتفاع فيديو YouTube؛ القيمة `0` تعطل التصفية |
| `YT_PROVIDERS` | حسب الإعداد الداخلي | ترتيب مزودات YouTube المستخدمة |
| `PIPED_INSTANCES` | غير مفعّل | عناوين مثيلات Piped مفصولة بفواصل عند تهيئتها |
| `INVIDIOUS_INSTANCES` | غير مفعّل | عناوين مثيلات Invidious مفصولة بفواصل عند تهيئتها |

لا تضع الأسرار في المستودع أو داخل ملفات الواجهة. أضف `SIGNING_SECRET` في إعدادات بيئة Vercel بقيمة عشوائية قوية.

## النشر على Vercel

المشروع مهيأ للنشر باستخدام `vercel.json` و`requirements.txt`، مع `app.py` كنقطة دخول Flask و`public/` لملفات الواجهة الثابتة.

1. ارفع المستودع إلى Git واربطه بمشروع Vercel.
2. اضبط متغيرات البيئة المطلوبة، وخصوصًا `SIGNING_SECRET`.
3. انشر المشروع ثم اختبر `/api/v1/health` والواجهة ومسارات API الأساسية.
4. راقب سجلات Vercel عند فشل مزود أو مصدر خارجي، واستخدم `X-Request-Id` لربط الطلب برسالة الخطأ.

## حدود تشغيلية وأمنية

- الكاش ومحددات المعدل ومزامنة الطلبات تعمل في ذاكرة نسخة Function الواحدة؛ لا تشكّل حدًا عالميًا بين جميع نسخ Vercel. استخدم Vercel Firewall أو مخزنًا مشتركًا إذا احتجت حماية موزعة.
- انتهاء مهلة انتظار الخيط لا يضمن إيقاف عملية الاستخراج الخلفية فورًا. المهلة تحد من وقت انتظار الاستجابة، لكنها ليست عزلًا قاطعًا للعملية.
- مسارات التنزيل والاقتصاص قد تمرر بيانات عبر الخادم؛ اقتصاص الصوت يستخدم ملفات مؤقتة في `/tmp`، لذلك راعِ حدود مدة التنفيذ والحمولة في Vercel.
- روابط الوسائط المباشرة قد تكون قصيرة العمر أو مرتبطة بترويسات المصدر. لا تخزنها طويلًا ولا تعتبرها روابط دائمة.
- أخطاء `401` و`403` و`429` أو فشل TLS قد تصدر من المنصة أو مزود خارجي، ولا تعني بالضرورة وجود خلل في Vercel.
- لا تستخدم `nocheckcertificate` أو إعدادات تتجاوز التحقق من TLS كحل افتراضي. لا تتضمن الخدمة آلية لتجاوز صلاحيات الوصول أو المحتوى الخاص.
